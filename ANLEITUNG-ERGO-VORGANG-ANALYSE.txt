============================================================
ERGO Vorgang-Analyse - Excel-Tool (v1.0)
============================================================

ZWECK:
  Liest die Email-Vorgaenge aus dem Tabellenblatt "Emails"
  (Output von ergo-email-batch.bas / Ordner_Scannen) und laesst
  ErgoGPT jeden Vorgang automatisch klassifizieren. Schreibt
  acht Zusatzspalten (I-P) zurueck.

AUSGABE-SPALTEN:
  I  Maklerpool          -> Fonds Finanz / BCA / JDC / blau direkt /
                            Fondsnet / Maxpool / WIFO / Aruna /
                            Apella / Netfonds / VEMA / Mr.Money /
                            Direktmakler / "" (unbekannt)
  J  Makler_Nachname     -> aus Signatur / From-Feld
  K  Makler_Vorname
  L  Klassifikation      -> Standardvorgang / Nicht-Standard
  M  Geschaefts_Typ      -> BUe einfacher Vertrag /
                            BUe Kundenverbindung /
                            Keine BUe
  N  Unterlagen_Angefragt -> ja / nein
  O  Sonderfall          -> Flottengeschaeft / Sondertarif /
                            Kein Sonderfall
  P  Sparte              -> Komposit / Leben / KV / Mehrere /
                            Unbekannt

============================================================

VORAUSSETZUNGEN:

  1) Modul mit Funktion ASK_ErgoGPT(prompt) MUSS bereits in der
     Mappe importiert sein. Den Code findest du im Repo unter
     'Test.txt' (oder in deinem bestehenden ErgoGPT-Modul).

  2) Tabellenblatt "GPT" mit folgenden Konfig-Zellen:
        A6  = Modell-Name           (z.B. "gpt-5.1" - EMPFOHLEN)
        A9  = Temperature           (z.B. 0.0 fuer deterministische Antworten)
        A12 = Tone                  (z.B. "Sachlich" oder leer)
        A20 = (optional) AI_RULES

  3) Cookie-Datei:
        F:\ExcelGPT-Cookie\Cookie.txt
     muss vorhanden und gefuellt sein (gleiches Setup wie fuer
     dein bestehendes ErgoGPT-Tool).

  4) Tabellenblatt "Emails" mit Spalten A-H (entsteht automatisch
     durch Outlook_Live_Abrufen oder Ordner_Scannen aus
     ergo-email-batch.bas):
        A Nr | B Datum | C Datum_ISO | D Absender_Name |
        E Absender_Email | F Betreff | G Text | H Anhaenge

============================================================

INSTALLATION (1x):

  1. Excel-Mappe oeffnen, in der bereits ASK_ErgoGPT importiert ist
     (oder erst Test.txt importieren - Alt+F11 -> Importieren).
  2. Alt+F11 -> Datei -> Datei importieren -> ergo-vorgang-analyse-v1.0.bas
  3. VBA-Editor schliessen, Mappe als .xlsm speichern.
  4. Alt+F8 -> 'Vorgaenge_Setup' ausfuehren.
       -> legt Sheet 'GPT' mit Default-Werten (gpt-5.1, Temp 0) an
       -> legt Sheet 'Anleitung' mit Step-by-Step-Beschreibung an
       -> fragt nach Cookie (entweder vorhandene Datei nutzen oder
          jetzt eingeben; wird nach F:\ExcelGPT-Cookie\Cookie.txt
          geschrieben - Verzeichnis wird ggf. erstellt)

============================================================

NUTZUNG:

  Schritt 1: Mails einlesen
     Mit Outlook_Live_Abrufen oder Ordner_Scannen (aus
     ergo-email-batch) das Tabellenblatt "Emails" fuellen.

  Schritt 2: Analyse starten
     Alt+F8 -> Vorgaenge_Analysieren -> Ausfuehren

     a) Cookie-Dialog erscheint:
        - Cookie-Datei vorhanden -> JA = nutzen / NEIN = neu eingeben
        - Cookie-Datei fehlt     -> JA = jetzt eingeben (wird gespeichert)
     b) Bestaetigung mit geschaetzter Laufzeit (~3-10 Sek/Zeile)

  Schritt 3: Ergebnisse pruefen
     Spalten I-P werden gefuellt. Bei jeder 5. Zeile speichert
     das Tool automatisch zwischen.

     Hervorhebungen:
       - "Nicht-Standard" -> hellgelb in Spalte L
       - "Flottengeschaeft" / "Sondertarif" -> hellrot in Spalte O

  Wieder-Aufnahme nach Abbruch:
     Bereits gefuellte Zeilen (Spalte I gefuellt) werden
     uebersprungen. Du kannst Vorgaenge_Analysieren also einfach
     nochmal starten - die Analyse setzt fort wo sie aufgehoert hat.

  Reset:
     Alt+F8 -> Vorgaenge_Analysieren_Reset
     Loescht Spalten I-P im Sheet "Emails".

============================================================

DOMAIN-LOGIK (kurz):

  BUe = Bestandsuebertragung. Makler A moechte den Bestand
  des Kunden von Makler B auf sich uebertragen. Eine VNR
  (Vertragsnummer) ist meistens in der Email angegeben.

  Entscheidend ist NICHT die VNR, sondern was uebertragen wird:
    - "BUe einfacher Vertrag":   nur dieser eine konkrete Vertrag
    - "BUe Kundenverbindung":    der gesamte Kundenstamm /
                                 alle Vertraege des Kunden
    - "Keine BUe":               Vorgang ist was anderes
                                 (Schaden, Antrag, Aenderung etc.)

============================================================

PROMPT ANPASSEN:

  Wenn du den Prompt an dein Tagesgeschaeft anpassen willst,
  oeffne ergo-vorgang-analyse-v1.0.bas und suche nach:
     Private Function BuildVorgangPrompt(...)
  Dort kannst du Maklerpool-Liste, Werteliste pro Feld und die
  Definitionen direkt editieren.

============================================================

HINWEIS:
  Das Tool LIEST nur Outlook/Excel und SCHREIBT in dein eigenes
  Excel-Sheet. Es schickt aber den Email-Inhalt an ErgoGPT
  (gpt.ergo.com), das ist datenschutzrechtlich nur OK, wenn
  ErgoGPT als interner Dienst freigegeben ist - was bei der
  ERGO der Fall ist.
